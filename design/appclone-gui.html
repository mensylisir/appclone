屏1 · 应用列表 — 组件映射与状态

窗口 / 头栏AdwWindow + AdwHeaderBar（CSD 圆角、居中粗体标题、右侧窗控圆点）
页面骨架AdwPreferencesPage → AdwPreferencesGroup → boxed AdwActionRow
分身开关AdwActionRow + GtkSwitch（add_suffix）——行主体激活进详情，开关独立操作不冒泡（GNOME Settings 通用模式）
未配置应用AdwActionRow + flat Button「配置…」 → 打开 discover 对话框（屏3）
状态：默认空态（AdwStatusPage，工具栏「空态演示」）错误（AdwBanner：bwrap 缺失）开关开启 → 副标题变为实例计数
跳转：点行体 → 屏2 详情；点「配置…」→ 屏3 对话框（首次配置模式）。

屏2 · 应用详情 — 组件映射与状态

实例行AdwActionRow + suffix 按钮组：启动（suggested）/ 删除（destructive-flat）；实例名支持内联重命名（contenteditable，失焦提交）
新建入口AdwActionRow（activatable）→ 打开屏3 对话框（新建分身模式）
档案信息AdwPreferencesGroup 只读行展示 AC_PATHS / 锁处理 / 实例根目录，等价 CLI 的 doctor 输出
操作反馈AdwToastOverlay + AdwToast——启动/删除均以 Toast 呈现，不打断列表；删除实际走回收站（gio trash）
状态：有实例零实例（仅剩「新建分身」行）删除后 Toast 确认 + 可撤销（v2）
跳转：头栏「←」→ 屏1；「重新探测 / 新建分身」→ 屏3。

屏3 · discover 路径勾选对话框 — 组件映射与状态

对话框AdwDialog（桌面居中、窗口内遮罩、Esc/取消关闭）；标题随入口切换「首次配置 · X」/「新建分身 · X」
路径行AdwActionRow + GtkCheckButton（add_prefix） + 语义 chip：配置（蓝，默认勾选）/ 缓存（默认排除）/ 公共目录（橙，强制排除并说明）
锁文件提示信息条（对应 CLI 的 AC_LOCKFILES 自动检测结论，无需用户勾选）
确认按钮suggested-action，选中 ≥1 个配置路径才可用——对应方案文档 §6.1「甄别公共目录」环节的 GUI 化
状态：默认（按语义预勾选）全不选（确认禁用）确认 → 写档案 + 建实例 + Toast，未配置应用升级为已支持
